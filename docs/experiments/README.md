# Experiments

Every experiment, whether a quick "which path should we take?" test or a long field run, gets a dated log here. Measurements decide direction, not assumptions.

- **Name:** `YYYY-MM-DD-short-topic.md`, e.g. `2026-10-12-rf-survey-home-vs-apiary.md`
- **Start from:** [TEMPLATE.md](TEMPLATE.md)
- **Photos, plots, raw CSVs:** `assets/YYYY-MM-DD-short-topic/`
- Negative and inconclusive results are logged too. They are often the most useful.
